# 坦克大战游戏

一个使用Python和Pygame开发的经典坦克大战游戏，可以在qPython环境中运行。

## 游戏特性

- 🎮 完整的坦克大战游戏体验
- 🎯 玩家坦克（蓝色）vs 敌方坦克（红色）
- 🛡️ 障碍物系统，增加策略性
- 💥 子弹碰撞检测和伤害系统
- 📊 实时血量和分数显示
- 🎨 简洁美观的图形界面
- 🤖 简单的AI敌人

## 安装要求

### 系统要求
- Python 3.6+
- qPython环境
- 支持图形界面的设备

### 依赖安装

在qPython中安装pygame：

```bash
pip install pygame==2.5.2
```

或者使用requirements.txt：

```bash
pip install -r requirements.txt
```

## 游戏控制

- **WASD键**: 移动坦克
- **左右方向键**: 旋转炮管
- **空格键**: 发射子弹
- **R键**: 游戏结束后重新开始

## 游戏规则

1. **目标**: 消灭所有敌方坦克
2. **血量**: 每个坦克有100点血量
3. **伤害**: 子弹造成20-25点伤害
4. **障碍物**: 棕色方块可以阻挡子弹
5. **胜利条件**: 消灭所有敌人
6. **失败条件**: 玩家坦克血量归零

## 运行游戏

在qPython中运行：

```python
python tank_battle.py
```

## 游戏截图

游戏包含以下元素：
- 蓝色玩家坦克（左侧）
- 红色敌方坦克（右侧）
- 棕色障碍物

## 故障排除

如果遇到问题：

1. **pygame未安装**: 确保已正确安装pygame
2. **显示问题**: 确保qPython支持图形界面
3. **性能问题**: 降低FPS或简化游戏元素

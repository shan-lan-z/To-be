# 坦克大战游戏

一个使用HTML5 Canvas和JavaScript开发的经典坦克大战游戏。

## 游戏特色

- 🎮 经典的坦克大战玩法
- 🎯 流畅的射击系统
- 🤖 智能的敌方AI
- 💥 炫酷的爆炸效果
- 📊 实时计分系统
- 🎨 现代化的UI设计

## 游戏功能

### 玩家坦克
- 绿色坦克，由玩家控制
- 3条生命
- 快速射击能力

### 敌方坦克
- 红色坦克，AI控制
- 随机移动和射击
- 从四个方向生成

### 游戏机制
- 击中敌方坦克获得100分
- 被敌方子弹击中失去1条生命
- 消灭所有敌人获得胜利
- 生命值归零游戏结束

## 控制方法

| 按键 | 功能 |
|------|------|
| W | 向上移动 |
| S | 向下移动 |
| A | 向左移动 |
| D | 向右移动 |
| 空格 | 发射子弹 |
| R | 重新开始游戏 |

## 游戏规则

1. **目标**: 消灭所有敌方坦克
2. **生命**: 玩家有3条生命
3. **计分**: 每击毁一个敌方坦克得100分
4. **胜利条件**: 消灭所有5个敌方坦克
5. **失败条件**: 生命值归零

## 技术特性

- **HTML5 Canvas**: 流畅的2D图形渲染
- **JavaScript ES6+**: 现代化的游戏逻辑
- **响应式设计**: 适配不同屏幕尺寸
- **碰撞检测**: 精确的物理碰撞系统
- **粒子效果**: 动态爆炸动画

## 如何运行

1. 下载所有文件到本地目录
2. 用浏览器打开 `index.html`
3. 开始游戏！

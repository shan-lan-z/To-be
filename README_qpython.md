# qPython 坦克大战游戏使用说明

## 🚀 快速开始

### 方法1：简单测试（推荐）
```bash
python simple_test.py
```

### 方法2：直接运行游戏
```bash
python tank_game.py
```

## 📁 文件说明

- **`simple_test.py`** - 基础环境测试
- **`tank_game.py`** - 简化版坦克大战游戏
- **`start_game.py`** - 完整版游戏启动器

## 🎮 游戏控制

- **WASD** - 移动坦克
- **左右方向键** - 旋转炮管
- **空格键** - 发射子弹

## 🔧 故障排除

### 如果遇到语法错误：
1. 确保运行的是正确的Python文件
2. 不要运行包含git命令的文件
3. 使用 `simple_test.py` 先测试环境

### 如果游戏无法启动：
1. 检查qPython是否支持tkinter
2. 尝试运行 `simple_test.py` 测试基本功能
3. 确保文件路径正确

## 💡 使用建议

1. **首次使用**：先运行 `simple_test.py` 测试环境
2. **游戏运行**：使用 `tank_game.py` 启动游戏
3. **如果简单版本正常**：可以尝试 `start_game.py` 完整版

## 🎯 游戏目标

- 消灭红色敌方坦克
- 避免被敌方子弹击中
- 获得更高分数

## 📱 qPython 提示

- 确保在qPython中选择正确的文件运行
- 避免运行包含特殊字符的文件
- 如果遇到问题，重启qPython应用
